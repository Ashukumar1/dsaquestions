# dsaquestions
DSA Questions
Here’s a categorized list of **important DSA (Data Structures and Algorithms) questions** — great for interview prep or mastering fundamentals:

---

### **1. Arrays**

* Find the maximum and minimum element in an array
* Reverse an array
* Find the “Kth” smallest/largest element
* Kadane’s Algorithm (maximum subarray sum)
* Move all zeros to the end
* Merge two sorted arrays
* Find duplicates in an array

---

### **2. Strings**

* Check for palindrome
* Reverse words in a string
* Count vowels, consonants, digits, and spaces
* Anagram check
* Longest substring without repeating characters
* String compression

---

### **3. Linked List**

* Reverse a linked list
* Detect a loop (Floyd’s cycle detection)
* Find the middle element
* Merge two sorted linked lists
* Remove duplicates
* Detect intersection point of two linked lists

---

### **4. Stacks & Queues**

* Implement stack using arrays/linked list
* Implement queue using two stacks
* Balanced parentheses
* Next greater element
* Evaluate postfix/prefix expressions

---

### **5. Trees**

* Inorder, Preorder, Postorder traversal
* Level order traversal (BFS)
* Height of a binary tree
